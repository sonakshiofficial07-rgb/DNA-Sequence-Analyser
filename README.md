# DNA-Sequence-Analyser
A bioinformatic project built using python and biopython for analyzing DNA sequences from FASTA files.

## Features
> Reads multi-FASTA files.
> Calculates nucleotide composition (A,T,G,C) of DNA sequence.
> Generates complementary DNA sequence.
> Calculates GC percentage.
> Translates the given DNA sequence into a protein.
> Checks whether the sequence contains the start codon (ATG).

## Example input
>Human
ATGCGATCGATCG

## Example Output
ID: Human
Length: 13
A: 3
T: 3
G: 4
C: 3
Complement sequence: TACGCTAGCTAGC
GC Content: 53.8%
Protein: MRSI
The given sequence contains a start codon
